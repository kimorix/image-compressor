图片压缩100% 本地处理

图片不会上传到任何服务器 · 支持批量 · 开源免费

GitHub 开源 ↗
拖拽图片到这里，或点击选择

支持 JPG、PNG、WebP、GIF（首帧）、BMP、SVG 等常见格式，也可直接 Ctrl+V 粘贴

开源项目：github.com/kimorix/image-compressor（MIT 协议，欢迎 Star / 提 Issue）
所有压缩均在你的浏览器内完成，不经过任何服务器
目标体积模式：对每张图自动二分调节质量，取不超过目标的最高画质；PNG 无损格式不适用。
注意：GIF 动图压缩后只保留首帧；JPEG 不支持透明通道，透明部分会填充白色。
